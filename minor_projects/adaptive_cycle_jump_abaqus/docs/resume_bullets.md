# Resume Bullets

- Developed a restart-based Abaqus/PBS workflow for adaptive cycle-jump prediction in cyclic Chaboche UMAT simulations.
- Implemented and HPC-tested a lightweight adaptive selector that identifies the largest accepted jump target from classified simulation evidence.
- Verified that target271 is the accepted extrapolated true-jump boundary from source cycle 250, while target272 is the first reproducible rejected jump.
- Separated extrapolated state-prediction error from Abaqus restart-continuity error using an exact/native target272 restart control with zero comparison error.
- Built a storage-light HPC workflow with lightweight evidence extraction, PBS accounting, restart diagnostics, and GitHub-ready visualization.
