# GitHub Description

Adaptive Cycle-Jump Prediction in Abaqus

A lightweight research workflow for accelerating cyclic Abaqus simulations using restart-based cycle jumping. The project combines Abaqus/PBS evidence, an adaptive Python selector, HPC smoke testing, and visualization. For the Chaboche UMAT benchmark, the selector identifies target271 as the largest accepted jump from source cycle 250 and rejects target272 because of extrapolated internal-state prediction error, not Abaqus restart continuity.
